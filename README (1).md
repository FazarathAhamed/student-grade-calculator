# 🎓 Student Grade Calculator

A Python-based Student Grade Calculator that computes grades, GPA, and pass/fail status for multiple subjects.

---


---

## 📋 Features

| Feature | Details |
|---------|---------|
| 👤 Student Info | Name + Student ID input |
| 📚 Multiple Subjects | Choose how many subjects to enter |
| 📊 Grade System | A+, A, B, C, D, F |
| 🎯 GPA Calculation | Scale: 0.0 to 4.0 |
| ✅ Pass/Fail Analysis | Subject-wise breakdown |
| 💾 Save to File | Results saved as a `.txt` file |

---

## 🎓 Grade Chart

| Marks | Grade | GPA Points |
|-------|-------|------------|
| 90 – 100 | A+ | 4.0 |
| 80 – 89  | A  | 3.7 |
| 70 – 79  | B  | 3.3 |
| 60 – 69  | C  | 3.0 |
| 50 – 59  | D  | 2.0 |
| 0  – 49  | F  | 0.0 |
